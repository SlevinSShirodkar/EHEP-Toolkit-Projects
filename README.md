# Experimental High Energy Physics (EHEP) Toolkit & Projects

Welcome! This repository serves as a portfolio of my data analysis projects in Experimental High Energy Physics (EHEP). It demonstrates my proficiency in applying modern computational frameworks, statistical tools, and physical logic to both real collider data and Monte Carlo (MC) simulations.

## Repository Overview

This repository is divided into two primary projects, reflecting my experience with both Python-based columnar analysis and traditional C++/ROOT object-oriented workflows:

 **`python-cms-opendata-analysis`** 
  * **Summary:** A Python-based analysis pipeline using the Scikit-HEP stack (`uproot`, `awkward`, `vector`) to analyze CMS DoubleMu open datasets. 
  * **Highlights:** Reconstructs the Standard Model Z-boson mass resonance and executes a search for beyond-the-standard-model (BSM) physics (heavy Type-III Seesaw fermions) via rare three-muon decay chains. Demonstrates efficient, loopless columnar data processing.

 **`summer-project`**
  * **Summary:** A custom C++ analysis framework built on the ROOT data analysis ecosystem. 
  * **Highlights:** Designed to reverse-engineer and deduce the physical processes of unlabelled Monte Carlo simulation samples. Features comprehensive particle object selection (Muons, Electrons, Photons, Jets, b-tags), kinematic/transverse mass calculations, and generator-level truth-matching (`GenPart`).

## Technical Competencies

* **Languages:** Python, C++
* **HEP Frameworks:** ROOT, Uproot, Scikit-HEP (Uproot, Awkward Arrays, Vector)
* **Physics Concepts:** 4-momentum Lorentz kinematics, invariant mass reconstruction, missing transverse energy (MET), background suppression, phase-space cuts, and Monte Carlo truth-matching.
